Optional recovery tests

Stage one edge case at a time

Manual-review queue

Copy 06_manual_review_required.md from 02 - OPTIONAL DROP-INS into the connected folder. Keep the Verdean tab visible for 5–10 seconds, then verify the queued file and Mark manually reviewed recovery.

Multiple contracts

Copy 05_alternate_matching_contract.txt into the connected folder. After the visible-tab refresh, choose the governing contract. The original contract produces seven differences; the matched alternate should produce zero. (For the scanned version, see the OCR scan demo.)

The recheck is intentionally limited to direct files about every five seconds while the tab is visible.

Finish

Return to a deterministic baseline

  1. Double-click Reset Test Kit.command and approve the prompt.
  2. The command removes only generated `_Verdean` output, known staged optional files, and `.DS_Store` metadata inside this kit.
  3. It restores all five canonical files and verifies each copy byte-for-byte.
  4. If Verdean is running, Chrome opens the reset URL, deletes the active saved demo workspace, clears the browser pointer, and returns Verdean to the disconnected landing page showing No folder connected.
  5. Run Verify Test Kit.command, then reconnect the prepared folder and rehearse again.

Inside the app, Start over also clears the active saved review workspace and returns to the landing page. It intentionally leaves source files and generated `_Verdean` copies untouched; use the Test Kit reset command for a complete rehearsal reset.

Troubleshooting

If the result does not match

Chrome cannot reach the app
Run Open Verdean.command again and keep its Terminal window open. The current URL is http://localhost:3000.
The app restores an old workspace
Double-click Reset Test Kit.command while Verdean is running, or click Start over inside Verdean. Both clear the active browser pointer and delete that saved demo workspace from D1.
I see more or fewer than five documents
Run Reset Test Kit.command, then Verify Test Kit.command. Reconnect only the prepared source folder. `.DS_Store` should never appear.
I do not see `_Verdean`
You used the read-only individual-file path or denied write access. Reconnect with Connect a folder and approve access.
The annotated preview says reconnect
The page was restored from D1. Verdean intentionally does not persist raw file text. Reconnect the prepared folder to restore the full preview.
Email does not send
Verdean only opens a prefilled draft in the Mac’s configured default email application. Select an account and press Send there. No automatic delivery occurs.
