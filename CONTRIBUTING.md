# Contributing

Thanks for helping improve Verdean.

## Before opening a pull request

- Keep credentials, environment files, customer documents, and personal data
  out of commits.
- Use the synthetic fixtures or clearly anonymized test data.
- Run `npm run typecheck`, `npm run lint`, and `npm test`.
- Keep product claims aligned with the current implementation and its stated
  limitations.
- Do not assume the MIT License grants rights to use the Verdean name or
  logos; those project assets are governed separately.

Small, focused pull requests are easiest to review. Please explain any
security, privacy, or data-retention implications in the pull-request body.
